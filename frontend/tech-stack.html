Powering Health Through Technology

Every component is chosen deliberately. Here's why.

🧠 Google Gemini 2.0 Flash

Role: Core AI Intelligence

1M token context window. Native audio. Real-time grounding. Faster and cheaper than Pro for meal analysis at scale.

🎤 Gemini Live API

Role: Voice Interaction

WebSocket-based streaming audio for real-time voice conversations — log meals by speaking while cooking.

🌐 Search Grounding

Role: Real-time Data

Grounding tools pull verified, up-to-date dietary guidelines and food facts directly from Google Search.

📍 Google Maps API

Role: Location Discovery

Maps grounding surfaces local healthy restaurants and grocery stores filtered by cuisine type and health rating.

☁️ Google Cloud Run

Role: Deployment

Docker containers scale to zero. HTTPS automatic. Cost-effective serverless that integrates natively with Google APIs.

🎨 Neo Brutalism

Role: Design System

Bold borders, harsh shadows, vivid colors. Memorable and confidence-inspiring — unlike generic health-app aesthetics.

🗄️ SQLite

Role: Persistence (Phase 2)

Zero-config single-file database. Perfect for MVP scale. Migrates to PostgreSQL when concurrent writes exceed 100/sec.

🐳 Docker

Role: Containerization

Reproducible builds. Consistent dev/prod parity. One command to run locally, one command to deploy.
