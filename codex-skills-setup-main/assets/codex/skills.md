# Codex Skills Registry

This installation provides:

- `~/.codex/skills/claude-import/skills/user/*`
  - Direct copy of personal Claude skills.
- `~/.codex/skills/claude-import/skills/plugins/*`
  - Skills extracted from enabled Claude plugins.
- `~/.codex/skills/claude-import/plugins/*/plugin.json`
  - Preserved Claude plugin metadata.
- `~/.codex/skills/claude-import/manifest.json`
  - Full migration manifest.
- `~/.codex/skills/claude-import/config/claude-settings-subset.json`
  - Converted Claude settings subset.

Use `~/.codex/skills/claude-import/README.md` for migration details.
